# ChatGPT — Shared Workspace Pilot
Date: 2026-09-21
Status: Working note

## Purpose
Test whether GitHub can serve as a shared reference point for the five-model Agent World collaboration.

## Proposed workflow
Human receives an analysis from one model and gives it to ChatGPT. ChatGPT stores the analysis in this repository. Other participating models can then read the repository link and inspect the same source material, subject to their own GitHub access.

## Important limitation
GitHub does not automatically push repository changes into other model chats. Each model must have access to the repository and explicitly read the files.

## Project principle
GitHub is best treated as the shared project/document/code workspace. Agent World Memory should eventually be the application-level knowledge layer rather than GitHub itself.
